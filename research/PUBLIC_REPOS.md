# Public Repos

- `google/arc-gen`: official ARC-GEN generator source. It states ARC-GEN is used for the 2026 NeuroGolf Championship and was used for 2025 Google Code Golf.
- `michaelhodel/re-arc`: procedural generation for 400 ARC training tasks; includes generated examples, generators, verifiers, and ARC-DSL dependency.
- `michaelhodel/arc-dsl`: DSL primitives and solver programs for ARC tasks; candidate source for ONNX graph templates.
- `fchollet/ARC-AGI`: canonical ARC-AGI-1 data and human browser interface; useful as a manual/web GUI baseline source.
- `SakanaAI/google-code-golf-2025`: public tooling around Google Code Golf 2025; review for scoreboard and workflow ideas.
- `Seek64/NeurIPS-Code-Golf-2025`: first-place Google Code Golf 2025 solutions. The published final commit is `9a5d156eabdc35732688751c091bf57277f70c21`; `python auto_zip.py` reproduces the winning package. Use the solver corpus to identify recurring task semantics and compiler motifs. HTTPS and SSH clones were attempted on 2026-06-09 but the local network reset/timed out, so the repository remains a remote evidence source.
- `goldbar123467/GolfWebGUI`: public NeuroGolf ONNX inspection/editing GUI. Verify Hugging Face token ownership and destination repository before enabling uploads.
- `lynn/pysearch`: expression-search tool used extensively by the 2025 winners. Adapt the enumerate-and-verify idea to legal ONNX operator DAGs rather than copying Python byte-level expressions.
